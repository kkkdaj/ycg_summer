수강신청 방법
1
기수와 이름 입력
메인 화면에서 기수를 선택하고 이름을 입력한 뒤 수강신청 버튼을 눌러주세요.
2
1교시 강의 선택
원하는 1교시 강의 카드를 탭한 뒤 1교시 신청하기 버튼을 눌러주세요.
신청됨 ✓ 표시가 뜨면 완료!
3
2교시 강의 선택
1교시와 다른 강의를 선택한 뒤 2교시 신청하기 버튼을 눌러주세요.
상단에 ✅ 수강신청 내역이 표시되면 모두 완료된 거예요.
강의 카드 상태 안내
카드에 표시되는 상태 신청됨 ✓ 내가 신청 완료한 강의
선택됨 현재 선택 중 (아직 신청 버튼을 누르지 않은 상태)
마감 정원이 가득 차서 선택 불가
2교시 신청됨 다른 교시에 이미 신청해 선택 불가
신청 내역 확인
1
메인 화면에서 이동
기수와 이름을 입력하고 수강신청 내역 확인 버튼을 눌러주세요.
2
시간표 확인
내 시간표 화면에서 신청된 강의와 장소를 확인할 수 있어요.
강의를 바꾸려면 수강신청 하러 가기를 눌러 다시 선택하세요.
주의사항
⚠️ 꼭 확인하세요 · 1교시와 2교시는 서로 다른 강의를 선택해야 해요.
· 정원이 초과된 강의는 선택할 수 없어요.
· 수강신청 기간에만 신청 버튼이 활성화됩니다.
· 기수와 이름이 기록에 남으니 정확하게 입력해주세요.
